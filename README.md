# 奶龙模组（My Lovely Milk Dragon）

给 Minecraft **26.3**（Fabric）加入「奶龙」：一个会跟着你走、会随地睡觉、会拆火把，
被打三下才会生气的生物。配套还有奶龙头、奶龙的奶、奶龙药水、奶蛋等一整套内容。

## 需要什么

| 组件 | 版本 |
|---|---|
| Minecraft | **26.3** |
| Fabric Loader | 0.19.5 或更高 |
| Fabric API | 0.161.0+26.3 |

## 内容一览

### 实体：奶龙

- 150 点生命、15 点护甲、免疫火焰；**白天不会自燃**，**和平难度下不会消失**
- 三种状态：**平静** / **愤怒** / **睡觉**，都会同步到客户端，各自一套贴图
  - 挨打累计 3 下，或睡觉时被打断 → 进入愤怒：移动速度提升，30 秒后自行平息
  - 会随机入睡，白天晚上都可能；睡够了自己醒，被打或被玩家靠近也会醒
- **只主动攻击村民**，不会主动攻击玩家；但谁打了它，它就会追杀谁
- **会拆掉周围 4 格内的火把**（普通 / 灵魂 / 铜火把，不含红石火把），掉落物照常产生
- 自然生成在村庄生物群系（高概率）和野外（低概率），**都不受光照限制**

### 物品

| 物品 | 说明 |
|---|---|
| **奶龙头** | 可佩戴在头上。戴上后附**绑定诅咒**且每 5 秒大笑一次；右键村民 / 灾厄村民 / 女巫给它戴上，30 秒后对方会**同化成奶龙** |
| **奶龙鳞片** | 酿造材料 |
| **奶龙的奶** | 喝下清除所有状态效果，并给予 +5 护甲和「幻听」（会时不时听见怪声）；**可以代替金苹果治愈僵尸村民**；喂给愤怒的奶龙可以让它平静下来 |
| **奶龙刷怪蛋** | 会出现在原版「刷怪蛋」物品栏页签里 |

### 方块

| 方块 | 说明 |
|---|---|
| **奶蛋** | 行为同原版龙蛋：能放置、受重力掉落、被打会瞬移。每次击杀奶龙都会掉落 |

### 药水

**奶龙药水** —— 用粗制的药水 + 奶龙鳞片酿造，普通 / 喷溅 / 滞留三种形态齐全。

### 掉落

奶龙的奶、硫磺、奶龙鳞片、奶蛋每次必掉；15% 概率掉附魔金苹果（受抢夺附魔影响）；
被爆炸炸死时额外掉一个奶龙头。

## 构建

```bash
./gradlew build        # 完整构建，产物在 build/libs/
./gradlew runClient    # 在开发环境里启动客户端（游戏数据在 run/）
```

需要 JDK 25。

## 开发状态

功能已实现，**贴图与音效尚未补齐** —— 贴图缺失时游戏内显示为紫黑格，不会崩溃。
